# OT Recon Tool

A lightweight OT (Operational Technology) network reconnaissance and risk detection tool.

## Features

* Network discovery (Nmap-based)
* OT protocol detection (Modbus, S7, OPC UA, etc.)
* Device classification (PLC, HMI, etc.)
* Risk detection engine
* Clean CLI output with Rich

## Usage

```bash
ot-recon scan 192.168.1.0/24
```

## Requirements

* Python 3.x
* Nmap
